# 深度自检框架

## 用途

当 Claude Code 生成了重要答案或设计方案后，使用此框架进行全面质量验证。特别适合：
- 架构设计方案的验证
- 复杂代码实现后的逻辑检查
- 评估报告的可靠性验证
- 任何高风险决策前的最终检查

## 使用方式

在完成初始答案后，按以下 8 个步骤逐一执行自检。自检完成后，等待用户确认再输出改进版本。

---

## 自检步骤

### 1. 质量自检

为答案质量打分（1-10 分），并具体、详细说明扣分的原因和改进方向。

### 2. 思维链检验

用 5 句以内的因果链重新梳理核心推导，确保每一句都能够追溯到事实和公理。

### 3. 关键假设检验

列出回答所依赖的 3-5 个关键假设，为每个假设的可信度打分（0-10 分，使用客观标准如引用来源或数据支持，并列出具体引用如论文链接如果可用）。然后，为每个假设说明数据以及经验依据。

### 4. 对立观点检验

提出与结论相反的两种合理立场，并且解释为什么选择当前答案。

### 5. 脆弱点排查

指出答案中最容易出错或者被质疑的环节，并给出如何改进这些环节以提升回复质量的建议。

### 6. 时效性检验

检索与主题相关的最新研究数据。简述这些数据是否会改变结论，以及可能会引起的要点。

### 7. 边界测试

说明在什么情况下答案会失效，并给出两到三个具体的边界场景。

### 8. 二次自检

如果重新回答这个问题，如何回答更好？请详细描述改进后的回答框架或关键变化。

---

## 输出格式

自检完成后，输出："**自检完成，等待确认。**"

在收到用户确认（如"确认"、"继续"、"好的"或"ok"）后，基于以上自检结果，重新生成一个完整的改进后答案。
